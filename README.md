# 📝 MyDailyNotesApp

A personal daily notes app built with Flask, HTML, CSS, and JavaScript. Write, edit, and organize your notes in a clean, responsive interface.

---

## 🚀 Features

- Create, edit, view and delete notes
- Dark mode support 🌙
- Search notes by title or content
- Clean UI built with HTML/CSS + JavaScript
- Flask backend with templating

---

## 🛠 Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Templating:** Jinja2
- **Styling:** Custom CSS
